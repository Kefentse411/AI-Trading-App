# AI-Trading-App
## Overview
A locally-hosted trading platform with ML-driven predictions, built using Node.js, Python, and Scikit-learn.

## Features
- User authentication with magic links
- Admin verification system
- AI chatbot integration
- Machine learning model for trading predictions

## Tech Stack
- Backend: Node.js
- ML/Data: Python, Scikit-learn
- Frontend: HTML, CSS

## What I Learned
Built this project with no prior experience using AI-assisted development, gaining hands-on skills in authentication systems, ML model integration, and full-stack architecture.
